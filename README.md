> ⚠️ **本分支 `v-0.7.7.3` 是测试版，尚未达到稳定版。**
> 功能、API、数据库结构、界面都可能随时变更，不保证向后兼容。
> 请勿用于正式交付或承载不可替代的数据。稳定版请见 `main` 分支。

## 这是什么形态的应用

**星芒现在是 Web 端应用**，界面在浏览器里运行。

仓库里的 Go 程序负责提供 HTTP 服务、读写本地数据、代理模型请求；前端是一个标准的 Vite 单页应用，
构建产物由 Go 用 `//go:embed` 内嵌进二进制。打包出来的 `xingmang.exe` 只是「让网页端能在一台机器上
凭一个可执行文件跑起来」的载体，**不是桌面客户端**。

启动后浏览器访问 `http://127.0.0.1:19825` 使用。桌面客户端形态属于早期版本，已不再作为主要形态维护。

> 目录名 `xingmang-desktop` 和 `go.mod` 的模块路径 `github.com/xingmang/xingmang-desktop`
> 是历史遗留命名，代码结构仍沿用，未做重命名。

## 功能

面向长篇小说的一体化工作台。数据全部落在本地：结构化数据在 SQLite，章节正文写成
书籍目录下的磁盘文件（库里只留索引），不上传云端。

三个贯穿全局的取舍：

- **模型自由**：不绑定服务商，任何兼容 OpenAI 协议的接口都能接，密钥只存本机。
- **AI 不擅自动手**：所有写入类操作（改正文、建角色、加图谱实体）都要先出提案，用户确认后才落地。
- **数据可带走**：卡包整包 JSON 导入导出，作品目录就是普通文件夹，不锁格式。

### 写作主线

| 模块 | 做什么 | 关键能力 |
|---|---|---|
| **我的小说**<br>`/books` | 所有作品的总入口 | 分卷 → 章节两层结构；卡片状态标签（创作中 / 已发布 / 已完结）可直接筛选；封面支持历史图回切；删除默认是归档，需二次确认才真删 |
| **创作**<br>`/write/:bookId` | 全屏正文编辑器 | 左侧章节树、右侧正文；AI 续写 / 改写 / 分析走工具栏，结果先预览再插入；独立全屏页，不受主站左栏干扰 |
| **提示词库**<br>`/prompts` | 提示词卡片与卡包的素材库 | 卡片分常规卡包 / 拆书卡包 / 独立卡片三类；卡包整包 JSON 导入导出，导入按字段白名单取；卡片可锁定，锁定后不被批量操作改到 |
| **提示预览**<br>`/prompt-preview` | 批量核对提示词全文 | 左列选卡片、右侧看全文；就地编辑回车即改；编辑受密码保护；支持按标签筛选 |
| **变量抽卡**<br>`/creative` | 把提示词变量随机填充，批量出灵感 | 先选卡包再选生成器，每个生成器带自己的固定提示词；模型返回的思考内容单列显示，不计入正文；生成结果可按条保留进历史 |

### 分析与素材

| 模块 | 做什么 | 关键能力 |
|---|---|---|
| **拆书库**<br>`/analysis/:bookId` | 把一本参考书拆成结构化档案 | 按章节分块喂给模型，产出人物 / 世界观 / 情节 / 文风；抽出的实体与关系直接进图谱；拆书用的提示词在「提示词库 → 拆书卡包」里可改 |
| **角色库**<br>`/characters/:bookId` | 角色卡集中管理 | 外貌、性格、关系、口头禅分层记录；角色跨章节复用；编辑后写作页的 AI 自动带上最新设定 |
| **wiki 图谱**<br>`/wiki-graph` | 人物、地点、事件的关系图 | 力导向布局自动生成；滚轮缩放、拖拽节点，松手即定不会回弹；可让 AI 分析整张图，实体过多时分块处理；支持筛选只留主要实体 |
| **AI 扫榜**<br>`/ai-ranking` | 抓各平台榜单看市场风向 | 四个数据源：番茄 / 七猫 / 起点 / 飞卢；筛选条件（分类、字数、变动）全部由接口动态返回；「变动」列显示名次涨跌，源未提供时留空；对比基准是「日期早于今天的最近一份快照」 |

### 工具与扩展

| 模块 | 做什么 | 关键能力 |
|---|---|---|
| **星芒 Agent**<br>`/agent` | 能带上下文、能调工具的多轮助手 | 12 个内置工具覆盖书籍 / 章节 / 角色 / 图谱的读写；写入类工具一律走提案—审批；历史会话在左栏，可另开新会话；回答可就地修改，改完进入后续上下文 |
| **工作流**<br>`/workflow` | 把多个 AI 步骤串成流水线 | 列表页是卡片墙，点进去是画布；节点含开始 / 结束 / AI 处理 / 上下文 / 文本 / 合并 / 循环 / 格式化 / HTTP 请求 / 图片；运行结果按节点分开查看，失败节点直接标出错误原因 |
| **插件系统**<br>`/plugins` | 本地插件的安装与管理 | 支持搜索、按分类筛选、安装本地插件包；每个插件带健康度评分，异常时先看它；卸载在卡片的管理菜单里 |
| **API 配置**<br>`/config` | 模型服务商、密钥与输出上限 | 先建渠道再测连通；模型的「最大输出」有三种来源（上游接口 / 内置表 / 手动填），界面用徽标标明来源；不认识的模型不猜值，发请求实测一次后缓存 7 天；报 `max_tokens` 超限时只需调小，不影响其它对话 |
| **个人中心**<br>`/profile` | 创作数据看板 | 作品数、状态分布、词数统计 |

### 教程中心

`/tutorial` 是独立布局的辅助区，不进主站左栏：

- **经验分享**：贴吧式分区列表，精华帖与全部分开，支持自定义分区与点赞。
- **功能速查表**：按主站左栏顺序逐页列出「这个页面干什么 + 关键操作」，是上手最快的入口。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Go 1.26（`net/http`，单二进制，前端通过 `//go:embed` 内嵌） |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus |
| 数据库 | SQLite（本地文件） |

## 目录结构

```
cmd/xingmang/        后端主程序（含 //go:embed 的前端产物挂载点）
cmd/migrate/         数据库迁移工具
cmd/decodebackup/    备份解码工具
internal/            业务代码：handlers / models / server / agent / bookstore / fanqie …
tools/release/       打包工具（编译 + 前端构建 + 归档）
tools/logogen/       示例资源生成
tools/agentprobe/    Agent 探测工具
web/src/             前端源码
build.ps1 / build.bat    发布打包入口
start-dev.ps1 / .bat     开发模式启动（后端 + Vite + 番茄桥）
```

## 环境要求

- Go **1.26.10**（`go.mod` 的 `go` 指令会触发 toolchain 自动下载）
- Node.js **^20.19.0 || >=22.12.0**
- 构建脚本为 PowerShell（Windows）

## 构建

```powershell
cd web
npm install

cd ..
.\build.ps1 -Version 0.7.7.3
```

产物：`dist\windows-amd64\`（`xingmang.exe` + `README.txt`），加 `-Zip` 时额外产出 `dist\V-0.7.7.3.zip`。

⚠️ **不要直接 `go build ./cmd/xingmang`**：该包用 `//go:embed all:web/dist` 内嵌前端产物，
而仓库中不含 `cmd/xingmang/web/dist`（属于构建产物）。`tools/release` 会先构建前端再自动同步到该目录。
需要手动构建前端时：

```powershell
cd web && npm run build
# 然后把 web\dist 的内容同步到 cmd\xingmang\web\dist
```

## 开发模式

```bat
start-dev.bat
```

同时拉起三个进程：Go 后端 `:19825`、Vite 开发服务器 `:5173`、番茄小说桥 `:19900`。
关闭后端会一并结束另外两个伴生进程。
