# 界面密度预算 · 设计规范

> 目的：把"信息负载"从一个主观感受，变成一条可执行、可审查的团队规则。
> 适用对象：星芒 AI 写作桌面端所有界面（Vue 组件：`views/`、`components/`、`layouts/`）。
> 心理学依据：认知负荷理论（Sweller）、米勒定律（工作记忆 7±2）、希克定律（选项越多决策越慢）、尼尔森启发式（系统状态可见性 / 一致性 / 极简美学）。

---

## 一、三条硬性预算（审查时逐条核对，不通过不进主分支）

### B1. 常驻可点元素 ≤ 9
单个界面「默认可见、可交互」的元素（按钮、图标按钮、Tab、开关、下拉触发、输入框）总数不得超过 **9 个**。

- 低频、非主路径的功能一律收进「更多」下拉 / 溢出菜单，不占常驻额度。
- 同一界面不同区域之间要**分配预算**，不能让单条工具栏独享全部 9 个。
- 反例：Books 每张卡片 6 个平权按钮、Write 顶部工具栏 7 按钮 + 编辑器工具栏 ~20 图标。
- 主次要有层级：每个界面最多 1 个主操作，其余为次要操作。

### B2. 弹出层深度 ≤ 2
用户从当前上下文切换到任意目标，途中的弹层级数不得超过 **2**（即：主界面 → 弹窗 → 弹窗内再套一层为止，禁止第三层）。

- 弹窗内再弹窗时，优先改用**抽屉（drawer）**、**向导分步**、**内联展开**、**独立路由页**。
- 反例：HistoryCenter 主弹窗 → 详情/追问 → 确认框（三层）；Books 封面 → 排行榜 → 预览（嵌套）。
- 一个界面的弹出层**总数**建议 ≤ 8，超过即视为"功能深度×概览性"失衡。

### B3. 单屏主信息流 ≤ 2
默认同时展示的**信息流**（画布 / 配置 / 输出 / 日志 / 消息流 / 表单 等各自算一个）不得超过 2 个；第三个必须默认折叠或按需展开。

- 反例：Write 目录 + 编辑器 + AI 面板三列。
- 主任务阶段不同，预算可以不同：**创作/阅读阶段从紧，管理/配置阶段从宽**（配置类界面用户预期高密度，但要结构化）。

## 二、补充规则（次一级，同样要遵守）

### C1. 表单字段 ≤ 7 个 / 屏
超出 7 个字段：用分组（`fieldset` 视觉分组 / `el-collapse` 折叠）或分步向导拆分，**默认只展示核心字段**，高级字段折叠。

### C2. 卡片可读字段 ≤ 6 个
列表卡片最多承载 6 个信息字段，超出部分用「摘要截断 + 展开」或「hover 渐进揭示」。摘要统一截断长度（如简介 100–120 字）。

### C3. 渐进呈现是默认手段
- 低频信息延迟暴露：hover 浮层、折叠、`简洁/高级` 开关。
- 弹窗内列表用「搜索 + 标签云 + 分页 + 每页限量」（参考 `ChatPanel/ChatMain.vue` 提示词弹窗，这是全项目渐进披露的标杆）。
- 操作按钮默认隐没、hover 显形（参考 `ChatPanel/ChatMessageList.vue`）。

### C4. 空状态必达
任何列表/结果/画布在无数据时必须给出空状态（`el-empty` 或自绘）+ 引导动作。全项目唯一遗漏是 `views/Config.vue`，新界面不得再出现空白表。

### C5. 一致性：同一功能只实现一次
- 同一功能不得在两个地方各写一套 UI（反例：正则编辑器在 `ChatDialog.vue` 与 `ChatPanel/ChatMain.vue` 重复实现）。
- 枚举值必须带可读标签，不得出现无说明的数字（反例：WorldBookEditor 插入位置 `0/1/2/3/7/8`）。
- 页面不得劫持全局主题状态（反例：BookAnalysis 进入时移除暗色主题、退出才恢复）。

### C6. 尊重 `prefers-reduced-motion`
装饰性动画（粒子、流光、辉光、星芒、脉冲）必须可关闭或自动降级。生成/加载中状态用**克制反馈**：图标 + 静态状态文本，不用大段闪烁动画。

---

## 三、审查方法（怎么用这条规则）

1. **逐界面过一遍**：打开模板，数「默认可见可点元素数」「弹出层最深级数」「同屏信息流数」，对照 B1/B2/B3。
2. 超标即开一个改造项，改造手段按优先级：**收纳（合并/收进下拉）→ 折叠（渐进展示）→ 分层（抽屉/向导/独立页）→ 删除重复**。
3. 新界面提交前走一遍自查清单：

| 检查项 | 通过 |
|---|---|
| 常驻可点元素 ≤ 9 | ☐ |
| 弹出层深度 ≤ 2 | ☐ |
| 同屏主信息流 ≤ 2 | ☐ |
| 表单 ≤ 7 字段/屏，多的已折叠或分组 | ☐ |
| 卡片 ≤ 6 字段 | ☐ |
| 有空状态 | ☐ |
| 无重复实现 / 无裸数字枚举 | ☐ |
| 动画可关闭（reduced-motion） | ☐ |
